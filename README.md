# iman

`iman` — менеджер сеанса IGUI и RetroArch для Linux. Он запускает меню,
принимает запрос на игру через локальный IPC, завершает GUI и запускает
эмулятор; после игры возвращает меню. Одновременно работает только один
дочерний процесс. В DRM-режиме менеджер удерживает дисплей между запусками.

Протокол, транспорт и общие примитивы дисплея/ввода предоставляет
[imanlib](https://github.com/idleboxed/imanlib).
Менеджер не устанавливает прошивку, не монтирует SD и не заменяет RetroArch
или ядра libretro.

## Быстрый запуск

Подготовьте комплект с iman, IGUI и нужными эмуляторами, затем запустите:

```sh
/путь/к/ROOT/system/iman/iman
```

Менеджер откроет меню и вернёт его после игры.
[Сборка и подготовка комплекта](docs/runtime.md#быстрый-запуск).

## Данные и ограничения

IPC и временные данные находятся в RAM. Снимки состояния сохраняются явно;
SaveRAM/SRAM проверяется раз в минуту и сохраняется при штатном выходе из игры.
Диагностическая сборка также экспортирует отчёты.

iman не переключает SD между RO/RW и не гарантирует устойчивость
к отключению питания. Уведомление в игре не подтверждает синхронизацию SD.
[Политика постоянных данных](docs/runtime.md#временные-и-постоянные-данные).
