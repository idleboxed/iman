# iman

## Правила работы

При работе с приложением обязательно следуй инструкциям [IDLE.md](IDLE.md).

- Команды Cargo выполнять из каталога `iman`; проверять только затронутый пакет.
- Python 3.12 нужен только для синтетических дочерних процессов Rust-тестов.
  Другие версии Python не включать в локальные проверки или CI.
- Тесты выполнять без оборудования, внешней сети и привилегий; локальный IPC
  и процессы изолировать временными каталогами. Офлайн-проверки не подтверждают
  работу на ARM-устройстве.
- Новые команды, аргументы и флаги CLI добавлять только после явного согласования.
- Линтеры и форматтеры запускать только по прямой просьбе владельца.
- Не менять SD, NOR, GPIO или питание без отдельного согласования опыта;
  команды с `sudo` на ПК выполняет владелец.

## Суть приложения

`iman` управляет жизненным циклом IGUI и RetroArch, передаёт состояние через
локальный IPC и владеет дисплеем между запусками дочерних процессов.
Общие протокол, транспорт и примитивы дисплея/ввода предоставляет `imanlib`.
Библиотека подключается через Cargo Git-зависимость с точным `rev`;
обновление коммита должно сопровождаться обновлением `Cargo.lock`.
Политика сеанса, конфигурация эмуляции, диагностика и экспорт остаются в `iman`.
Приложение не зависит от исходников или ресурсов IGUI, iroll и BOX2.

IPC, журналы и временные данные находятся в проверенном tmpfs.
Автоматическое переключение SD между RO/RW не реализовано; не заявлять
устойчивость к отключению питания. Границы записи описаны в
[README](README.md#данные-и-ограничения) и [данных сеанса](docs/runtime.md#временные-и-постоянные-данные).
